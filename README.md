Quando conoscerai nuove persone e vorrai aggiungerle alla lista:

1- Apri il file Excel sul tuo computer, aggiungi la riga e salva.
2- Vai sulla pagina principale della tua repository su GitHub.
3- Clicca Add file -> Upload files.
4- Trascina il file Excel aggiornato.
5- Scrivi "Aggiunto Mario Rossi" (o quello che vuoi) nel box del commit e clicca il tasto verde (GitHub sovrascriverà il vecchio file con quello nuovo e dalla mattina dopo userà la lista aggiornata).
